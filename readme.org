Inspired by [[https://github.com/robxu9/bash-static][bash-static]] from robxu9.

Uses static cross-musl-based toolchains provided by [[https://aur.archlinux.org/packages/muslcc-arm-linux-musleabihf-cross-bin][muslcc-arm-linux-musleabihf-cross-bin]] from AUR.

But it can be used elsewhere by utilizing the same toolchain downloaded from [[http://musl.cc/][musl.cc]].

06_xxhash +does not work+ works but xxhsum binaries are not static.

07_rsync  builds +without+ with xxhash statically linked.

08, 09, 10, 11 do not build.

May fix this in future.

Or if you manage to build xxhsum statically, please let me know.

I mostly use this for my RPi Zero W.
